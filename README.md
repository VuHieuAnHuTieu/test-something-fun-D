# Local Business Intelligence AI Agent

A secure, 100% local Business Intelligence AI Agent orchestrating deterministic tools for database querying, analytics, visualization, and executive reporting.

## Tech Stack
- **AI Brain**: Ollama (`qwen2.5-coder:7b`) on local GPU
- **UI**: Streamlit
- **Database**: MySQL (`sakila_extended`) with least-privilege read-only access
- **Security**: SQLGlot Abstract Syntax Tree (AST) validation
- **Analytics & Math**: Pandas
- **Charts**: Matplotlib
- **Reporting**: ReportLab (PDF)
- **Validation**: Pydantic
